# 🎧 Paperpile Radio

論文のNotebookLM音声概要を自動配信する個人ポッドキャスト。
認知科学・HCI・ロボティクス論文を日本語で。

**🎵 聴く**: [https://shks.github.io/paperpile-radio](https://shks.github.io/paperpile-radio)  
**📡 RSS**: [https://shks.github.io/paperpile-radio/feed.xml](https://shks.github.io/paperpile-radio/feed.xml)

## 使い方

### ポッドキャストアプリに登録
Overcast / Apple Podcasts / Pocket Casts で「URLで追加」し、
`https://shks.github.io/paperpile-radio/feed.xml` を登録してください。

### Webで聴く
[https://shks.github.io/paperpile-radio](https://shks.github.io/paperpile-radio) を開くだけ。

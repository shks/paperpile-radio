# 自閉スペクトラム症（ASD）における表情産生のメタ分析：包括的ブリーフィング・ドキュメント

本文書は、自閉スペクトラム症（ASD）を有する個人と、定型発達（TD）または非自閉症の臨床比較群との間における「表情の産生」の違いを検証したメタ分析（Trevisan et al., 2018）に基づき、その主要な知見、理論的背景、および実用的な示唆をまとめたものである。

---

## 1. エグゼクティブ・サマリー

本研究は、ASDにおける非言語コミュニケーションの重要な側面である「感情的な表情の産生」に関する既存研究（計39研究、67の分散した効果量、総サンプル数 N=1358）を統合した初の包括的なメタ分析である。

**主な結論：**
*   **総合的な差異：** ASD群と対照群の間には、表情の産生において中程度（g = -0.481）の有意な差が認められた。
*   **質と頻度の低下：** ASD群は表情を表示する頻度が少なく、持続時間も短い。また、その表情は「質が低い（不自然、機械的）」、あるいは「社会的文脈にそぐわない」と判断される傾向がある。
*   **状況による変動：** 自然な社会的相互作用や無意識の模倣（不顕性）において差異が顕著になる一方で、実験室で指示を受けて表情を作る（顕示性）場合には、その差は縮小する。
*   **補償メカニズム：** 年齢の上昇や高い知的機能は、定型発達の規範に近い表情を産生する能力（補償戦略）の発達に寄与している可能性が高い。

---

## 2. 表情産生における主要テーマの分析

研究チームは表情の能力を多角的に捉え、以下の7つの変数に基づいて分析を行った。

### 2.1 表情の質と正確性
ASDの個人が産生する表情は、客観的あるいは主観的な評価において以下の特徴を持つ。
*   **表情の質（Expression Quality）：** 最も大きな群間差（g = -1.028）が見られた項目の一つである。ASD群の表情は、観察者から「ぎこちない」「奇妙」「機械的」と評価されることが多い。
*   **意図的な表情の正確性（Voluntary Expression Accuracy）：** 言語的な指示や意図的な模倣を求められた際、ASD群は感情を正確に表現するスコアが低い傾向にある。

### 2.2 社会的相互作用と模倣
表情が社会的な文脈でどのように機能するかについても、顕著な差異が確認された。
*   **社会的適合性（Social Congruency）：** 感情の共有や文脈に応じた適切な表情の使用において、ASD群は大きな困難（g = -1.265）を示す。自閉症児は、共同注視の場面で母親と感情を共有する可能性が低い一方で、自己没頭的な活動中にポジティブな感情を示すといった報告がある。
*   **自動的模倣（Automatic Mimicry）：** 他者の表情を無意識に模倣する能力が低く、その正確性も劣る。これは対人関係の構築や共感の形成に影響を与える可能性がある。

### 2.3 維持されている機能
一方で、以下の側面については群間差が認められず、ASDにおいて比較的維持されていると考えられる。
*   **感情の強度（Intensity）：** 驚愕や不快な臭いに対する反応としての表情の強さは、対照群と変わらない。
*   **反応時間（Reaction Time）：** 刺激を受けてから表情が現れるまでの速さに有意な差は見られなかった。

### 2.4 表情産生に関連する用語の定義

| 用語 | 定義 |
| :--- | :--- |
| **不随意（Involuntary）** | 意識的な制御なしに起こる表情。情動的覚醒や自動的模倣を含む「傘」のような総称。 |
| **随意（Voluntary）** | 指示（「悲しい時はどんな顔？」等）や社会的儀礼に基づき、意図的に作られる表情。 |
| **自然発生（Spontaneous）** | 内部の情動的覚醒の結果として生じる不随意な表情。 |
| **自動的模倣** | 提示された顔刺激を無意識かつ自発的に複製するプロセス。 |
| **表情の模倣** | 提示された顔刺激を、指示に従って意図的に複製すること。 |

## 3. 調節変数による分析（なぜ差異が生じるのか）

メタ分析の結果、ASD群と対照群の差異の強さは、以下の要因によって変動することが明らかになった。

*   **引き出し戦略（不顕性 vs 顕示性）：** 自然な状況下（不顕性）での表情産生は、指示された状況（顕示性）よりも群間差が大幅に大きい。これは、ASDの個人が「何をすべきか」が明確な管理された環境では能力を発揮しやすいが、日常の非定型な相互作用では困難に直面することを示唆している。
*   **年齢と知的機能：** 年齢が高く、IQが高いほど、群間差は小さくなる。これは、蓄積された人生経験や高い認知能力を用いて、社会的規範に合わせた表情を産生する「補償戦略」を学習しているためと考えられる。
*   **マッチング手続き：** 年齢とIQの両方で厳密にマッチングを行った研究ほど、報告される群間差は小さくなる傾向がある。

## 4. 重要な引用と文脈

> 「ASDの参加者は表情を表示する頻度が少なく、時間も短く、他者と表情を共有したり、実在の顔や顔刺激を自動的に模倣したりする可能性が低い。」

*   **文脈:** メタ分析によって明らかになった、ASDにおける表情産生の量的な不足と社会的機能の欠如を要約した一節。

> 「IQが高く、蓄積された人生経験が豊富な人は、『定型発達』の規範により近い表情を産生する能力が高いことが示唆される。」

*   **文脈:** 年齢と知的機能が表情能力の個人差に与える影響を説明しており、発達に伴う学習の可能性を示している。

> 「ASDの個人は自然に表情を産生する方法が他の人々とは異なる可能性があるが、実験室の設定で感情を表現するよう求められた場合には、その障害は少なくなると考えられる。」

*   **文脈:** 不顕性（自然）と顕示性（指示）の引き出し戦略による差異の大きさを比較した結論であり、臨床的評価における環境設定の重要性を説いている。

## 5. 実用的な示唆と今後の展望

本メタ分析の知見は、ASDの理解と支援において以下の示唆を与える。

### 5.1 社会的機能への影響
*   表情の「ぎこちなさ」や「不自然な外観」は、第一印象の形成や社会的な円滑さを損なう要因となり得る。
*   自動的模倣の欠如は、他者の感情を推論する能力（感情認識）の低下に寄与している可能性がある。

### 5.2 臨床および教育への適用
*   **補償戦略の理解：** 高機能のASD者が「適切な表情」を作っている場合でも、それは自然な表出ではなく多大な認知的努力を要する補償戦略の結果である可能性がある。
*   **評価環境の考慮：** 個人の表情能力を評価する際は、構造化された指示場面だけでなく、自然な相互作用の観察が不可欠である。

### 5.3 未来の研究方向
*   **客観的測定の導入：** 人間の評価者による主観を排除するため、AIや機械学習を用いた表情解析ソフトウェア（FACS等に基づく）の活用が期待される。
*   **メカニズムの解明：** 表情の特異性が、低次の処理（ミラーニューロン・システムの機能不全）によるものか、高次の処理（メンタライジング/心の理論の欠如）によるものかを解明する必要がある。
*   **個人差の考慮：** アレキシサイミア（失感情症）や抑うつといった、ASDに併存しやすい特性が表情産生に与える影響についても、さらなる調査が必要である。

# 心臓と自己：心拍と視覚の統合が自己顔認識および内受容的皮質処理に及ぼす影響

本資料は、Selら（2017年）による研究論文「Heartfelt Self: Cardio-Visual Integration Affects Self-Face Recognition and Interoceptive Cortical Processing（心に触れる自己：心拍と視覚の統合が自己顔認識と内受容的皮質処理に与える影響）」に基づき、身体的自己意識の構築における内部信号（内受容）と外部信号（外受容）の統合メカニズムを解説するブリーフィング・ドキュメントである。

---

## 1. エグゼクティブ・サマリー

身体所有感は、身体の「外側」からの信号（視覚・触覚など）と「内側」からの信号（心拍などの内受容）の両方の統合に依存している。本研究は、修正された「エンフェースメント錯覚（Enfacement Illusion）」を用い、心拍と視覚情報の統合が自己顔認識および心拍に対する脳の反応をどのように変化させるかを調査した。

主な結論として、参加者自身の心拍と同期して明滅する他者の顔（モーフィング画像）を提示すると、非同期の場合と比較して、他者の顔を自己として認識する傾向（自己同定）が強まることが示された。また、この統合プロセスは、心拍誘発電位（Heartbeat Evoked Potential: HEP）の振幅減少を伴うことが明らかになった。重要な点として、これらの効果の強さは、個人の心拍を正確に知覚する能力である「内受容精度（IAcc）」と正の相関があり、内受容精度が高い個人ほど、心拍と視覚の統合による自己表現の更新が顕著であることが確認された。

---

## 2. 主要テーマの詳細分析

### 2.1 心拍と視覚の統合による自己顔認識の変容（実験1）
実験1では、参加者の心拍と同期、または非同期で明滅するシェードを、参加者自身の顔と見知らぬ他者の顔を合成したモーフィング画像上に投影した。

*   **主観的等価点（PSE）の変化**: 同期的な心拍・視覚刺激（40%自己/60%他者の画像）を受けた後、参加者は他者の特徴をより多く含む画像を「自分である」と判断するようになった。これは、外部の視覚情報と内部の心拍信号が一致することで、自己の境界が他者へと拡張されたことを示唆している。
*   **単方向の変化**: この変化は自己認識の判断においてのみ生じ、他者の顔の認識自体には影響を与えなかった。これは、先行研究における視覚・触覚によるエンフェースメント錯覚と同様のパターンである。

### 2.2 心拍誘発電位（HEP）による神経学的解析（実験2）
実験2では、脳波（EEG）を用いて、刺激提示中の心拍に対する皮質反応を測定した。

*   **HEPの変容**: 同期刺激条件下では、右中心頂領域（right centro-parietal ROI）において、R波発生から195～289msの範囲でHEPの振幅が減少した。
*   **コントロール条件**: フクロウの顔を用いた対照実験ではこの効果が見られなかったことから、HEPの変容は単なる視覚的同期の効果ではなく、自己に関連する社会的刺激（顔）と身体信号の統合特有の現象であると言える。
*   **右半球の重要性**: この反応が右半球で顕著であったことは、右半球が内受容と外受容の統合、および自己認識において重要な役割を果たしているという既存の証拠を裏付けている。

### 2.3 内受容精度（IAcc）の調整役割
本研究の最も顕著な知見の一つは、内受容精度（IAcc）が行動レベルと神経レベルの両方で効果を調整している点である。

| 測定項目 | 内受容精度（IAcc）が高い個人の特徴 |
| :--- | :--- |
| **自己顔認識** | 同期刺激による自己同定の強化（PSEのシフト）がより顕著に現れる。 |
| **HEP振幅** | 同期刺激に対するHEP振幅の減少（皮質減衰）がより大きく現れる。 |
| **メカニズム** | 心臓信号に対する感度が高いため、外部刺激との統合が容易になり、自己表現の更新が促進される。 |

### 2.4 予測符号化（Predictive Coding）による解釈
研究グループは、これらの結果を「予測符号化」の枠組みで説明している。

*   **感覚の衝突と減衰**: 自身の心拍（本来は私的な内部情報）が外部の他者の顔から発せられるという「感覚の衝突」が生じた際、脳はこの衝突を解決しようとする。
*   **サリエンスの調整**: 脳は内部の内受容信号のサリエンス（重要性）を弱め、外部の視覚情報に大きな重みを置くことで、自己のメンタルモデルを更新する。HEPの振幅減少は、この内受容信号の皮質における減衰を反映していると考えられる。

## 3. 重要な引用とその背景

> 「同期的な（対 非同期的な）心拍・視覚刺激は、他者の顔との自己同定を高め（実験1）、刺激提示中、同期性は皮質内受容処理の電気生理学的指標である心拍誘発電位（HEP）の振幅を変化させた（実験2）。」

*   **背景**: 本研究の核心的な発見をまとめた一節。心拍という内部信号が視覚という外部信号と統合されることで、自己の定義そのものが再構築されることを示している。

> 「内受容情報が自己認識という文脈で視覚情報に重く依存する場合、心拍・視覚同期の条件下では、外部の証拠に従って自己のメンタル表現を更新するために、感覚入力が減衰される。」

*   **背景**: 神経学的結果（HEPの減少）の理由を説明している。脳が「自分」を定義し直すために、一時的に内部信号の処理を抑制する適応的なメカニズムを示唆している。

> 「内受容精度が高い個人は、心拍・視覚の統合に関わる身体的錯覚に対して、より高い感受性を示した。これは、内受容情報が誘発メカニズムの一部である場合、心拍信号へのアクセスが良いほど、他者の顔との統合が促進されるためである。」

*   **背景**: 過去の視覚・触覚ベースの錯覚（ゴムの手錯覚など）では、内受容精度が高いほど錯覚にかかりにくいとされていた。しかし、心拍を直接利用する本手法では逆の結果となった理由を、心拍信号自体が統合の「鍵」となっているためであると解説している。

## 4. 実行可能な知見（Actionable Insights）

1.  **多感覚統合による自己意識の理解**: 身体所有感や自己認識の評価において、視覚や触覚といった外受容だけでなく、心拍のような内受容信号を考慮することが不可欠である。
2.  **個体差の考慮（IAccの活用）**: 臨床や心理学的な介入において、内受容精度（IAcc）を測定することで、特定の感覚刺激に対する個人の反応性や自己境界の柔軟性を予測できる可能性がある。
3.  **自己意識障害への示唆**: 離人症・現実感喪失症候群など、身体的自己意識が損なわれる疾患において、心拍処理の異常（HEPの低下など）が診断や病態理解の指標となる可能性がある。
4.  **予測符号化モデルの適用**: 自己認識のプロセスを、内部モデル（予測）と外部入力（予測エラー）の不一致を最小化する動的なプロセスとして捉えることで、自己意識の可塑性をより深く研究できる。

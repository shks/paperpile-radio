# バーチャルリアリティにおける視点の連続体：一人称・三人称視点の再定義と設計指針

本文書は、Matthias Hoppeらによる研究「There Is No First- or Third-Person View in Virtual Reality: Understanding the Perspective Continuum (2022)」に基づき、バーチャルリアリティ（VR）における視点知覚の性質、およびそれがユーザーのプレゼンスや身体化に与える影響を分析したブリーフィング・ドキュメントである。

## エグゼクティブ・サマリー

伝統的なデスクトップゲームにおいて、一人称視点（1stPP）と三人称視点（3rdPP）は明確に区別された概念として扱われてきた。しかし、本研究はVR空間においてこの境界が曖昧であり、視点は離散的な二択ではなく「連続体（Continuum）」として存在することを明らかにした。24名の参加者を対象とした実験の結果、カメラの位置やスケーリング（視点の高さ）を操作しても、ユーザーの知覚は単純に一人称か三人称かに二分されることはなかった。

三人称視点を用いたVR体験は、一人称視点と比較してプレゼンス（存在感）、エージェンシー（主体性）、身体所有感が低下する傾向にあるが、これは「レガシー・バイアス（VRは一人称であるべきという固定観念）」の影響も示唆されている。一方で、視点を意図的に操作することは、ホラーゲームの恐怖緩和、戦略ゲームの俯瞰、露出療法などのヘルスケア分野において、新たなデザインの可能性を切り拓くものである。

## 主要テーマの詳細分析

### 1. 視点の連続体（Perspective Continuum）の概念
VRにおける視点は、技術的にはカメラの位置に関係し、概念的にはユーザーが環境をどう知覚するいかに関係している。
*   **非二分的な知覚:** 実験データの統計分析（超過質量検定）により、ユーザーの視点知覚は単峰性でも二峰性でもないことが示された。つまり、多くのユーザーが「一人称と三人称の中間」の感覚を抱いている。
*   **主観的な解釈:** 同じ三人称のカメラ位置であっても、あるユーザーは「自分自身を後ろから見ている（幽体離脱体験）」と感じ、別のユーザーは「自分の動きで別のキャラクターを操作している（人形使い）」と感じる。

### 2. プレゼンスと身体化への影響
視点の変化は、VR体験の質を定義する主要な指標に顕著な影響を及ぼす。

| 指標 | 三人称視点（3rdPP）における傾向 | 統計的有意性 |
| :--- | :--- | :--- |
| **プレゼンス (IPQ)** | 一人称視点に比べ大幅に低下。 | 有意差あり (p < .001) |
| **エージェンシー (Agency)** | 自分の動きが仮想体に反映されている感覚が低下。 | 有意差あり (p < .001) |
| **身体所有感 (Ownership)** | 仮想の体を「自分のもの」と感じる感覚が低下。 | 有意差あり (p < .001) |
| **自己位置 (Self-Location)** | 仮想空間内での自分の位置感覚が変化。 | 有意差あり (p = .01) |
| **ゲーム体験 (GEQ)** | 没入感やフロー、ポジティブな感情のスコアが低下。 | 有意差あり (p = .046) |

### 3. カメラ設定とスケーリングの役割
研究では、視点（1stPP/3rdPP）に加えて、カメラの高さとスケーリング（Normal, Diorama, Giant）の影響も調査された。
*   **Normal（通常）:** キャラクターや敵と同じサイズ。
*   **Diorama（ジオラマ）:** カメラが高く、床が腰の高さにある（テーブルトップゲームのような感覚）。
*   **Giant（巨大）:** 非常に高い視点で、足元に床がある。
*   **分析結果:** 意外なことに、カメラの高さやスケーリングの変化は、視点が「一人称的か三人称的か」という知覚スコアに対して統計的に有意な影響を与えなかった。

## 重要な引用とコンテキスト

> 「VRにおける一人称視点と三人称視点の概念は、伝統的なデスクトップゲームから直接翻訳することはできない。視点は環境の離散的な特徴ではなく、連続体として知覚される。」

**コンテキスト:** VRでは頭部トラッキングにより常に「世界を覗き込む」一人称的な体験がベースにあるため、三人称視点のカメラ位置であっても、ユーザーの解釈が多様に分かれることを強調している。

> 「三人称視点は、プレゼンス、エージェンシー、所有感を意図的に低下させるための設計上の決定として利用できる。」

**コンテキスト:** 身体化の低下を単なる欠点ではなく、恐怖心の緩和や、臨床場面での刺激への段階的な露出といったポジティブなツールとして活用できる可能性を示唆している。

## 推奨される用語法

研究チームは、VR設計における混乱を避けるため、従来の1stPP/3rdPPに代わる新しい用語体系を提案している。

| 提案用語 | 定義・内容 |
| :--- | :--- |
| **Within-Character view** | 視点がキャラクターの内部にある（伝統的な1stPP）。 |
| **Out-of-Character view** | 視点がキャラクターの外部にある（伝統的な3rdPP）。 |
| **Within-Character embodiment** | 仮想キャラクターを自分の体そのものとして知覚する。 |
| **Out-of-Character embodiment** | 操り人形を操作しているような感覚で体験する。 |
| **Within-Character control** | 頭部や手の動きをミラーリングして操作する。 |
| **Out-of-Character control** | ゲームパッドのボタン入力等で操作する。 |

## 実用的なインサイトと設計への応用

### ゲームデザインとナラティブ
*   **視点の切り替えによる情緒的関与:** 物語の進行に合わせて「キャラクターそのものになる（Within-Character）」状態と、俯瞰して「キャラクターを見守る（Out-of-Character）」状態を切り替えることで、ナラティブの幅を広げることができる。
*   **戦略とアクションの融合:** 戦略ゲームにおいて、軍隊に命令を下す際は俯瞰視点を用い、特定のユニットを直接操作する際には直接制御と三人称視点をシームレスに移行させる設計が可能になる。

### アクセシビリティと安全性
*   **強度の調整:** ホラーゲームや過激な体験において、プレイヤーが恐怖を感じすぎた場合、即座にOut-of-Character viewへ移行させることで、心理的負荷を軽減する「イージーモード」やアクセシビリティ機能として機能する。
*   **プレイエリアの警告:** ユーザーが物理的なプレイエリアの境界に近づいた際、一人称から三人称視点へ引き離すことで、没入を解き、現実世界の安全性に気づかせることができる。

### 医療・セラピーへの応用
*   **段階的露出療法:** クモ恐怖症などの治療において、最初はOut-of-Character embodiment（遠くから操作する）から始め、徐々にWithin-Character embodiment（自分がその場にいる）へ移行することで、患者の不安をコントロールしながら治療を進めることが可能になる。
*   **カウンセリング:** 自己対話パラダイムにおいて、異なる視点を採用することで、自分自身の問題を客観的な第三者の立場から解決するアプローチを支援できる。

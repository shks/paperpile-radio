# 神経科学ロボティクス：存在幻覚の制御された誘導とリアルタイム評価に関するブリーフィング・ドキュメント

## エグゼクティブ・サマリー

本文書は、Bernasconiら（2022年）による研究に基づき、ロボット工学と認知神経科学を統合して「存在幻覚（Presence Hallucination: PH）」を実験的に誘導・評価する新しい手法についてまとめたものである。幻覚は精神疾患や神経変性疾患において頻繁に見られる重要な症状であるが、その主観的かつ予測不能な性質から、科学的な解明が困難であった。

本研究で開発された「ロボット誘導存在幻覚（riPH）」プロトコルは、健康な参加者および患者（パーキンソン病、統合失調症、レビー小体型認知症など）に対し、特定の感覚運動の矛盾（時空間的遅延）をロボットを用いて与えることで、臨床的に関連のある存在幻覚を、安全かつ繰り返し、リアルタイムで誘導することを可能にした。これにより、幻覚の行動学的・神経学的バイオマーカーの特定が進み、新たな診断・予後予測ツールの開発への道が開かれた。

## 主要テーマの詳細分析

### 1. 存在幻覚（PH）の臨床的意義と課題
存在幻覚とは、「近くに誰もいないにもかかわらず、誰かがいるという鮮明な感覚」と定義される。
*   **疾患別の発生率:**
    *   **パーキンソン病（PD）:** 患者の25～42%に発生。認知機能低下や認知症、死亡リスクの上昇を予測する指標とされる。
    *   **統合失調症:** 患者の約46%が経験。
    *   **レビー小体型認知症（DLB）:** 20～40%の患者に見られ、主要な診断基準の一つである。
*   **研究の障壁:** 従来の自己報告に基づく評価は、忘却や解釈の偏り、社会的スティグマによる報告控えの影響を受けやすい。また、薬物や視覚刺激を用いた従来の誘導法は、臨床的な幻覚を正確に再現できず、意識障害を伴うリスクがあった。

### 2. ロボット誘導手法のメカニズム
本プロトコルは、参加者の身体運動と、それに対応する身体への触覚フィードバックの間に「感覚運動の矛盾」を生じさせることで幻覚を誘導する。

| 設定項目 | 内容 |
| :--- | :--- |
| **フロント・ロボット** | 参加者が目の前で指を挿入し、ポーキング（突く）動作を行う。 |
| **バック・ロボット** | フロント・ロボットの動きに連動し、参加者の背中に触覚刺激を与える。 |
| **同期条件 (0ms遅延)** | 自分の動きと同時に背中が触られる感覚（「自己接触」の錯覚）。 |
| **非同期条件 (500ms遅延)** | 動きと触覚の間に遅延が生じ、他者が後ろにいる感覚（riPH）が誘導される。 |

### 3. 神経学的基盤と脳内ネットワーク
fMRIを用いた研究により、riPHに関連する特定の脳ネットワークが特定された。
*   **主要領域:** 下前頭回（IFG）、前部島、内側前頭前野、上側頭溝後部（pSTS）。
*   **共通ネットワーク:** 脳卒中や局所てんかんによる臨床的PH患者に見られる脳損傷部位と、ロボット誘導によるネットワークは解剖学的に重複している。
*   **疾患特有の異常:** パーキンソン病のPH患者では、左下前頭回と左上側頭溝後部（pSTS）の間の連結性に破壊が見られ、これが幻覚への感受性を高めている可能性がある。

### 4. 統合失調症および他の疾患への応用
*   **統合失調症:** 幻覚や自己エージェンシーの喪失は、自己生成アクションの感覚予測の異常に関連すると考えられている。ロボットを用いた感覚運動刺激は、音声知覚の誤り（幻聴に関連）を誘発し、早期精神病患者の弁別精度を低下させることが示された。
*   **レビー小体型認知症（DLB）:** DLB患者においても共通のPHネットワークに変化が見られる。この手法は、正常な加齢に伴う衰退と初期の認知症を区別するための診断ツールとしての活用が期待されている。

## 重要な引用

> 「幻覚は、対応する外部刺激が存在しない中で発生する異常な知覚体験として定義される。……幻覚研究における大きな欠点は、臨床的な幻覚に類似し、繰り返し誘発可能で、実験条件によって変化させることができる、特定の短時間の幻覚を誘導できる手法が存在しないことである。」

> 「（ロボット誘導による）これらの結果は、腕と体幹からの身体信号を含む特定の感覚運動の矛盾が、軽度から中程度の存在幻覚を誘導するのに十分であることを示しており、PHを自己の身体の感覚運動信号のソースとアイデンティティの誤認に結びつけている。」

> 「健康な個人において幻覚が生じるメカニズムを研究することは、薬物治療、併存疾患、神経心理学的欠陥、あるいは意識障害といった患者特有の交絡変数なしに、純粋な脳メカニズムの理解を深めることを可能にする。」

## 実用的な洞察と今後の展望

1.  **リアルタイム評価の実現:** 従来の回顧的な自己報告に頼ることなく、制御された条件下で幻覚が発生している瞬間の脳活動や行動データを取得できる。
2.  **診断・予後予測ツールとしての活用:** 
    *   パーキンソン病患者において、riPHに対する感受性が高い（非同期遅延に対する反応が強い）場合、将来的な視覚幻覚や認知機能低下の早期指標となる可能性がある。
    *   非同期遅延を0msから500msまで変化させることで、幻覚に対する感受性（勾配）や報告のバイアスを定量化できる。
3.  **臨床現場への導入:** 
    *   プロトコルの完了には約3時間を要し、中程度の認知神経科学スキルと最小限のコーディング経験で実施可能である。
    *   MRI対応ロボットを用いることで、疾患ごとの神経回路の破壊状況を詳細にマッピングできる。
4.  **倫理性と安全性:** 薬物誘導法と比較して、riPHは副作用が少なく、オン・オフの制御が容易であり、倫理的な懸念を抑えながら体系的な実験研究を行うことができる。

## 実験ワークフローの概要

### 行動研究
1.  **初期化:** フロントおよびバック・ロボットの設置とキャリブレーション。
2.  **トレーニング:** 同期条件下でデバイスの操作に慣れる（約1Hzの頻度で背中を探索）。
3.  **時空間刺激テスト:** 同期（0ms）と非同期（500ms）の各2分間のセッションをランダム順で実施。
4.  **評価:** 質問票（Supplementary Table 1）による主観的評価、および自己位置推定や計数推定などの客観的指標の測定。

### fMRI研究
*   仰臥位（仰向け）で操作可能なMRI対応ロボットを使用。
*   30秒間の刺激と18秒間の休息を繰り返すブロックデザイン。
*   運動のみ（接触なし）および接触のみ（運動なし）のコントロールタスクを組み込み、純粋な幻覚に関連する活動を抽出する。

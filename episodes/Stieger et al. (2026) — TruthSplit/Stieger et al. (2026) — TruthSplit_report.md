# TruthSplit：多角的視点に基づく議論分析と「条件付き妥当性」の運用に関するブリーフィング・ドキュメント

## エグゼクティブ・サマリー

本文書は、聖ガレン大学の研究チームによって開発された、多角的な視点から議論を分析するインタラクティブ・システム「TruthSplit」の機能、アーキテクチャ、およびその背景にある理論的枠組みをまとめたものである。

現代社会における分断の深化に対し、従来の議論分析ツールは、論理構造や議論の質、説得力といった「議論自体の特性」の評価に留まっており、解釈の背後にある世界観や価値観を十分に扱えていなかった。TruthSplitは、同一の主張であっても、解釈者が持つ価値観や前提条件によって結論が異なるという**「条件付き妥当性（Conditional Validity）」**の概念を導入し、大規模言語モデル（LLM）と構造化された世界観プロファイルを用いて、議論の相違を可視化・分析する。

本システムは、単に議論の「正誤」を判定するのではなく、なぜ異なる結論が導き出されるのかという規範的・構造的な理由を明らかにすることで、教育者、学生、研究者、アナリストの批判的思考と他者の視点理解を支援することを目的としている。

## 主要テーマの詳細分析

### 1. 条件付き妥当性（Conditional Validity）の運用化
TruthSplitの中核となる概念は、「結論の妥当性は前提から導かれる論理だけでなく、解釈の枠組みとなる価値観、仮定、概念定義に依存する」という考え方である。
*   **視点依存の分析:** 同じ事実データに基づいても、個人の優先順位（例：個人の自由 vs 集団の安全）によって結論は正反対になり得る。
*   **脱・二元論的評価:** 議論を「正しい」か「誤り」かの二元論で分類するのではなく、特定の枠組みにおいて論理的一貫性があるかどうかを評価する。

### 2. 構造化された世界観知識ベース
システムは、政治哲学的文献に基づき、以下の6つの主要な世界観を構造化されたプロファイルとして保持している。
*   **リバタリアン（Libertarian）**
*   **宗教的保守（Religious-Conservative）**
*   **エコロジー社会民主主義（Ecological Social-Democrat）**
*   **ポピュリスト・ナショナリスト（Populist-Nationalist）**
*   **共産主義（Communist）**
*   **新反動主義（Neo-Reactionary）**

各プロファイルは、コアとなる価値観の重み付け、重要概念の定義、意思決定フレームワーク、および16のイデオロギー次元にわたる因子スコアを含み、計算可能な形式で定義されている。

### 3. 多段階分析パイプライン
TruthSplitは、入力を以下の6つのステージで処理し、詳細な比較分析を生成する。

| ステージ | 内容 |
| :--- | :--- |
| **議論抽出** | テキストから主張（Claim）、前提（Premise）、仮定（Assumption）を分解・抽出する。 |
| **一貫性テスト** | 3層の自然言語推論（NLI）を用い、(1)論理的妥当性、(2)世界観内部の一貫性、(3)世界観を跨いだ合意形成度を評価する。 |
| **概念リンキング** | 主張に含まれる概念（例：「自由」）が、各世界観でどのように定義されているかを特定する。 |
| **世界観分析** | 構造化されたプロファイルに基づき、LLMが各視点からの解釈、立場（賛成/反対）、推論チェーンを生成する。 |
| **相違分析** | 価値観の衝突、仮定のギャップ、定義の違いなど、意見の不一致の根本原因を特定する。 |
| **可視化** | 3D因子空間やコンバージェンス・フロー（推論の収束・分岐図）を用いて相違をインタラクティブに表示する。 |

## 重要な引用と文脈

> **「同じデータを見ても、一方は『個人の責任を損なう』としてベーシックインカム（UBI）に反対し、もう一方は『持続可能な活動に従事するための経済的安全保障』として支持する場合がある。両者は論理的な欠陥があるのではなく、より深い構造的な違い――世界の仕組みに関する仮定、価値観の優先順位、そして『自由』や『正義』といった概念の定義の違い――に起因している。」**
*   **文脈:** 現代の分断がいかに単純な論理ミスではなく、規範的な前提の相違から生じているかを説明する導入部での例示。

> **「TruthSplitは、不一致を解決しようとするのではなく、異なる規範的な出発点からどのように異なる結論が導き出されるのかを明示することを目的としている。」**
*   **文脈:** システムの設計思想。意思決定支援ツールではなく、分析・教育ツールとしての立場を明確にしている。

> **「条件付き妥当性：結論の妥当性は、それが導き出される前提だけでなく、それが解釈される価値観、仮定、概念的定義にも依存するという考え方。」**
*   **文脈:** 本プロジェクトの理論的基盤。Rawls（1993）やLougheed（2021）の哲学を計算機科学に応用した定義。

## 評価結果の要約

専門家（哲学専攻学生）および非専門家（政治学、計算機科学等の学生）を対象とした評価により、以下の知見が得られた。

*   **ユーザビリティ:** 非専門家にとっても「相違分析（Divergence Analysis）」の内容は理解しやすく、平均4.07/5の高い評価を得た。視覚的なアピール（5.00/5）も非常に高く評価されている。
*   **世界観の再現性:** 専門家による検証の結果、特に「エコロジー社会民主主義」「リバタリアン」「共産主義」の表現は現実の政治的言説をよく反映しているとされた。
*   **LLMの堅牢性:** Claude、GPT、Gemini、DeepSeekなど、異なるLLMモデルを使用しても生成される推論の質に大きな差はなく、TruthSplitの「構造化プロンプト」手法がモデル間の差異を標準化することに成功している。

## 実行可能なインサイトと今後の展望

分析結果に基づき、以下の活用方法と発展可能性が示唆される。

1.  **教育への統合:** クリティカル・シンキングや市民教育のカリキュラムにおいて、他者の視点を理解するためのツールとして活用する。
2.  **世界観ビルダーの構築:** ユーザーが独自の世界観プロファイルを定義できる機能を備えることで、既存の枠組みに囚われない、より多様な視点からの分析を可能にする。
3.  **マルチモーダル対応:** テキストやPDFだけでなく、音声や動画（政治討論など）をソースとした議論分析への拡張。
4.  **ジャーナリズムへの応用:** ニュース記事の背景にあるイデオロギー的なバイアスを可視化し、読者のメディア・リテラシー向上に寄与する。

TruthSplitは、AIが「単一の正解」を提示する段階を超え、規範的な不一致を透明化し、より深い対話と相互理解を促進するための強力な基盤を提供する。

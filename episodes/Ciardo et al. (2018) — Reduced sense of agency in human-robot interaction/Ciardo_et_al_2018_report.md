# 人間とロボットの相互作用における主体感の減退に関する調査報告書

## エグゼクティブ・サマリー

本報告書は、人間がロボットなどの人工エージェントと相互作用する際、自らの行動とその結果の因果関係を認識する「主体感（Sense of Agency: SoA）」がどのように変化するかを分析したものである。Ciardoら（2018年）の研究に基づき、具現化されたロボット（Cozmo）との共同作業が、人間同士の相互作用で見られる「責任の分散」と同様の現象を引き起こすことを明らかにする。

研究の結果、人間はロボットが共に作業に従事している状況において、自分一人で作業する場合よりも主体感を低く評価することが示された。これは、人間がロボットを単なる「動くコンピューター」ではなく、意図を持つエージェントとして認識している可能性を示唆しており、将来の社会ロボットの設計や緊急時の対応策を策定する上で極めて重要な知見である。

---

## 主要なテーマの詳細分析

### 1. 責任の分散と主体感（SoA）のメカニズム
社会心理学において「責任の分散」は、他者の存在によって個人の行動の可能性が低下したり、結果に対する責任感が薄れたりする現象として知られている。
*   **主体感（SoA）の定義:** 自分の行動によって外部の出来事をコントロールしているという主観的な感覚。
*   **他者の影響:** 人間同士の相互作用（HHI）においては、他者が存在することでSoAが低下し、これが責任の分散の根底にあるメカニズムだと考えられている。

### 2. 実験手法：Cozmoロボットを用いた共同作業
本研究では、具現化された人工エージェントが人間に与える影響を測定するため、以下の実験デザインが採用された。

| 項目 | 内容 |
| :--- | :--- |
| **参加者** | 成人18名（平均年齢24.3歳） |
| **使用ロボット** | Anki Robotics社製「Cozmo」（物理的な筐体を持つロボット） |
| **タスク内容** | 膨らむ風船が破裂する前にストップボタン（キューブ）を押すゲーム。 |
| **コスト構造** | 停止が遅いほど失点は少ないが、破裂すると最大失点となる。 |
| **条件設定** | **単独条件:** 参加者のみが操作。 / **共同条件:** 参加者とCozmoの両方が操作可能。 |
| **評価指標** | 8段階のリッカート尺度による「主体感（コントロール感）」の自己評価。 |

### 3. 主な分析結果
実験データの統計的分析（線形混合モデル等）により、以下の事実が判明した。

*   **主体感の有意な低下:** 参加者が自ら風船を止めた場合であっても、Cozmoが傍にいる「共同条件」では「単独条件」に比べて主体感のスコアが有意に低かった。
*   **結果の質による影響:** 失点が多い（ネガティブな結果）ほど、主体感の評価が低くなる傾向が確認された。
*   **行動の変容:** 共同条件では、単独条件よりも風船を破裂させるミス（Missed trials）が少なかった。これは参加者がロボットの存在に合わせて戦略を調整したことを示している。

### 4. 具現化（Embodiment）の重要性
過去の研究では、コンピューターとの相互作用（HCI）においては、この主体感の低下が見られないという報告があった。しかし、本研究で物理的な身体を持つ「ロボット」においてSoAの低下が確認されたことは、エージェントの「具現化」が人間の社会認知に決定的な影響を与えることを証明している。

## 重要な引用とその背景

> 「他者が存在すると、自らの行動と外部の出来事の間の認識された関係、すなわち主体感（SoA）が減少する。この効果は、責任の分散に寄与すると考えられている。」

*   **背景:** 研究の導入部において、なぜSoAの研究が社会的行動（グループでの意思決定のバイアスや緊急時の介入遅延など）を理解するために重要であるかを説明している。

> 「結果は、参加者が風船を止めることに成功した際、失点量にかかわらず、単独条件よりも共同条件においてSoAを低く評価したことを示した。これは、ロボットとの相互作用が、他の人間との相互作用と同様にSoAに影響を与えることを示唆している。」

*   **背景:** 本研究の核心的な発見であり、ロボットが単なる道具ではなく、社会的エージェントとして人間の心理に影響を与えていることを裏付けている。

> 「人間はロボットを、意図的なエージェントとして認識しているのか、あるいは『具現化されたコンピューター』として認識しているのかは、これまで不明であった。」

*   **背景:** 研究の目的を定義する一節。結果として、人間はロボットを「意図的なエージェント」に近い形で捉えていることが示唆された。

## 実践的な洞察（Actionable Insights）

本研究の成果は、人間とロボットが共存する未来の社会設計において、以下の視点を提供できる。

1.  **緊急時対応ロボットの設計:**
    人間はロボットがいることで「自分がやらなくても誰か（ロボット）がやるだろう」という責任の分散を起こす可能性がある。そのため、緊急事態を扱うロボットは、人間側の反応の遅れを予期し、自律的かつ迅速に検知・行動できる能力を備える必要がある。

2.  **社会ロボットの振る舞い:**
    ロボットの設計において、人間に過度な責任放棄をさせないよう、適切なタイミングで人間の注意を喚起したり、役割分担を明確にしたりするインタラクション・デザインが求められる。

3.  **意思決定の最適化:**
    グループ作業においてロボットを導入する場合、人間の主体性が損なわれ、リスクの高い選択や努力の放棄（社会的手抜き）が生じる可能性を考慮すべきである。

4.  **心理学的研究への応用:**
    具現化されたロボットを用いた実験プロトコルは、高い「生態学的妥当性（実際の社会状況に近い性質）」と厳密な「実験的制御」を両立できるため、人間の社会認知メカニズムを解明するための強力なツールとなる。

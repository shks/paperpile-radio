# コンピュータ生成顔を用いたアンフェイスメント（自己顔同化）錯覚：実験的分析と知見

## エグゼクティブ・サマリー

本文書は、La Roccaら（2023年）による研究論文「Look at me now! Enfacement illusion over computer-generated faces」を分析したブリーフィング・ドキュメントである。

この研究は、他者の顔を自己の顔の一部として知覚する「アンフェイスメント（自己顔同化）錯覚」が、最新のソフトウェアで作成されたコンピュータ生成顔（CG顔）に対しても生じるかを検証したものである。23名の若年成人を対象に、視覚・触覚刺激（visuotactile）、視覚・運動刺激（visuomotor）、および単純提示（exposure）の3つの条件下で、同期（synchronous）および非同期（asynchronous）の刺激を与え、その効果を比較した。

主な結論として、CG顔においても同期的な多感覚刺激によって強力なアンフェイスメント錯覚が誘発されることが確認された。特に、物理的な接触を伴う視覚・触覚刺激や、特定の動作を模倣する視覚・運動刺激は、単純な顔の提示よりも高い効果を示した。本研究は、バーチャルリアリティ（VR）環境における自己表現や顔処理研究の新たな手法として、CGアバターの活用の有効性を実証している。

---

## 主要テーマの詳細分析

### 1. アンフェイスメント錯覚（Enfacement Illusion）の概念
アンフェイスメント錯覚とは、自己の身体所有感（Embodiment）が外部の身体へと移行する現象の顔バージョンである。自己の顔と他者の顔に対して同期的な多感覚刺激（触覚や運動など）を与えることで、他者の顔を自己のものとして、あるいは自己の顔が他者の顔に似てきたかのように感じる主観的な変化が生じる。

*   **多感覚統合の役割:** 本研究では、視覚情報と触覚、あるいは視覚情報と運動情報のタイミングが一致する「同期条件」が錯覚の誘発に不可欠であることが示された。
*   **自己顔の優位性:** 脳には「自己顔優位性（self-face advantage）」が存在し、自己の顔を認識するシステムは特殊なものとされるが、この錯覚を利用することで、他者の顔（またはアバターの顔）に対しても同様の心理的・神経的反応を拡張できる可能性が示唆されている。

### 2. コンピュータ生成顔（CG顔）の有効性と利点
本研究では「Character Creator」というソフトウェアを使用し、実写写真から変換された高精度な3Dアバターを使用した。

*   **カスタマイズ性:** CG顔を使用する最大の利点は、顔の特徴（サイズ、配置）、表情、民族性、性別、年齢などを実験目的に合わせて自由かつ精密に編集できる点にある。
*   **リアリズムの影響:** CG顔は微細な肌の質感や欠陥を欠く場合があるが、本研究の結果、高品質なテクスチャを持つアバターであれば、実写の顔と同様にアンフェイスメント錯覚を十分に引き起こせることが証明された。

### 3. 刺激条件の比較分析
実験では、以下の3つの刺激タイプが比較された。

| 刺激タイプ | 内容 | 主な結果 |
| :--- | :--- | :--- |
| **視覚・触覚 (Visuotactile)** | アバターと参加者の頬を同時に筆などで触れる。 | 最も強力な所有感（Ownership）を誘発した。 |
| **視覚・運動 (Visuomotor)** | アバターの頭の動き（頷く、振る）に合わせて参加者も動く。 | 視覚・触覚と同等の強い効果が確認された。 |
| **単純提示 (Exposure)** | アバターを単に見つめる（正位置または倒立）。 | 他の2条件より効果は弱いが、正位置での提示は倒立提示より錯覚が生じやすい。 |

*   **ガイド付き運動（Guided Movement）の導入:** 本研究の新規性の一つは、オンラインのトラッキングシステムを使わず、ビデオのアバターの動きに合わせて参加者が動く「ガイド付き運動」を採用した点である。この手法でも錯覚が十分に生じることが確認され、高価な装置なしでの実験の可能性を開いた。

### 4. 測定指標と感受性の違い
研究では「身体所有感（Embodiment）質問票」と「アンフェイスメント質問票」の2種類が使用された。
*   **結果の乖離:** 「身体所有感」に関する質問（Ownership, Agency, Location）の方が、同期と非同期の差をより敏感に捉えることが判明した。
*   **質問票の課題:** 従来のアンフェイスメント質問票は、刺激の同期性による主観的変化を捉える上で改善の余地があることが示唆されている。

## 重要な引用とその背景

> **「同期刺激と非同期刺激の差は、質問票の身体所有感（embodiment）項目においてより顕著であった。」**

*   **背景:** 実験結果の分析において、同期刺激が非同期刺激よりも強い錯覚を生むことは確認されたが、その差は「顔が自分のものであると感じるか（所有感）」や「動きをコントロールしていると感じるか（エージェンシー）」という項目で特に強く現れたことを示している。

> **「ガイド付き運動としての視覚・運動刺激がアンフェイスメントを誘発できることが確認された。」**

*   **背景:** 従来、身体所有感の研究では参加者の自発的な動き（能動的運動）が重要視されてきたが、本研究の「アバターの動きを追う」という受動的なガイド付き運動でも十分に自己と同化できることが示された。これにより、実験環境の簡略化が可能になる。

> **「CG顔を研究の基準として使用することは、認知および社会的領域におけるVR実験の幅広い応用に繋がる。」**

*   **背景:** 写真やビデオなどの静的な刺激に代わり、編集可能なアバターを標準的な刺激として使用できることが実証されたため、今後の心理学研究における柔軟性が飛躍的に高まることを強調している。

## 実践的示唆（Actionable Insights）

1.  **VR・メタバースへの応用:** アバターの顔に対して自己同化を感じさせるためには、視覚的な一致だけでなく、ユーザーの動きや触覚刺激との「時間的な同期」を優先させる設計が重要である。
2.  **臨床研究への活用:** アンフェイスメント錯覚は、統合失調症や自閉スペクトラム症（ASD）などの自己認識や他者理解に課題を持つ臨床群の研究において、非侵襲的な介入・調査ツールとして活用できる可能性がある。
3.  **研究手法の簡略化:** 高度なモーションキャプチャ装置がなくても、同期したビデオ映像とガイドされた運動（メトロノーム等を使用）を組み合わせることで、精度の高い実験を一般的なコンピュータ画面上で実施可能である。
4.  **質問票の選定:** 今後の研究においてアンフェイスメントの効果を測定する際は、従来の顔専用の質問票だけでなく、所有感やエージェンシーを問う一般的な身体所有感質問票を併用することが、より感度の高いデータ収集に繋がる。

## 付録：質問票の構成要素（表1に基づく）

| カテゴリ | 下位要素 | 質問の内容（要約） |
| :--- | :--- | :--- |
| **身体所有感** | **所有感 (Ownership)** | 自分の顔を直接見ているように感じた / ビデオの顔が自分のものであるように感じた |
| | **エージェンシー (Agency)** | ビデオの顔を動かせると感じた / 顔のコントロールを失っていると感じた（逆転項目） |
| | **位置 (Location)** | ビデオの顔が自分の顔がある位置にあると感じた / ビデオの顔への接触を自分でも感じられた |
| **アンフェイスメント** | **同化感** | 他者の顔が自分の顔だと感じた / 自分の顔が他者の顔に似てきたと感じた |
| | **特性・社会的認識** | 自分の顔の経験が通常より鮮明でなくなった / ビデオの人物が魅力的、あるいは信頼できると感じた |

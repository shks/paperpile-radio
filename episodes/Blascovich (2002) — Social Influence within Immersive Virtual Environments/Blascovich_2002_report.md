# 没入型仮想環境（IVE）における社会的影響：ブリーフィング・ドキュメント

本文書は、ジム・ブラスコビッチ（Jim Blascovich）による研究「没入型仮想環境内における社会的影響（Social Influence within Immersive Virtual Environments）」に基づき、デジタル仮想空間における人間行動と社会的相互作用のダイナミクスをまとめたものである。

## 1. エグゼクティブ・サマリー

本研究は、社会心理学の理論を没入型仮想環境（IVE）に適用し、デジタル空間における「他者」がいかに個人の思考、感情、行動に影響を与えるかを分析している。中心的な知見は、社会的影響の度合いは「社会的存在感（Social Presence）」の関数として変化し、それは「エージェンシー（代理性）」と「行動のリアリズム」という外部要因、および「自己関連性」や「反応システム」といった内部要因によって決定されるという点にある。実験を通じて、IVEは従来の心理学研究の限界を超え、自己同一性の操作や、意識に上らない低次の心理プロセスの解明を可能にする強力なツールであることが実証されている。

## 2. 主要概念と用語の定義

IVEにおける社会的行動を理解するために、以下の用語が定義されている。

| 用語 | 定義 |
| :--- | :--- |
| **仮想環境 (VE)** | 合成された環境を非合成のものとして知覚させる、感覚情報の構成体。 |
| **没入型仮想環境 (IVE)** | 個人がその環境内に存在しているという心理状態（存在感）を生じさせるVE。 |
| **存在感 (Presence)** | 自身がある環境内に存在していると知覚する心理状態。物理的環境でも常に全人的であるとは限らない。 |
| **社会的存在感 (Social Presence)** | 自身が対人環境内に存在していると知覚する心理状態。 |
| **エージェンシー (Agency)** | 仮想的な他者を「実在の人物の表現」として知覚する程度。 |
| **行動のリアリズム (Behavioral Realism)** | 仮想の物体や人物が、物理世界と同様に振る舞う度合い。 |

### エージェンシーの連続体
エージェンシーは、以下の両極を持つ連続体として捉えられる。
*   **エージェント:** 非人間的な手段（コンピュータ・アルゴリズム等）によって完全に制御されていると知覚されるもの。
*   **アバター:** 実在の人間によってオンラインで完全に制御されていると知覚されるもの。
*   **ハイブリッド:** 人間と非人間双方の手段によって部分的に制御されていると知覚されるもの。

## 3. 社会的影響の閾値モデル（Threshold Model）

社会的影響がいつ、どのように発生するかを説明するために「閾値モデル」が提唱されている。このモデルでは、社会的影響はある一定の閾値を超えた時にのみ作用するとされる。

### 3.1 社会的影響に影響を与える要因

#### 外部要因
1.  **エージェンシー:** 相手が人間（アバター）であると信じるほど、社会的存在感が高まり、社会的影響を受けやすくなる。
2.  **行動のリアリズム:** 相手の振る舞いが写実的であるほど（例：アイコンタクト、表情の動き）、社会的存在感が高まる。
    *   *重要ポイント:* Interpersonal communicationにおいては、写真のような外見の忠実度（フォトグラフィック・リアリズム）よりも、表情の動きなどの「表現のリアリズム」の方が重要である。

#### 内部要因
1.  **対人的自己関連性 (Interpersonal Self-relevance):** その相互作用が個人の自己概念や目標にとっていかに重要か。重要な信念に関する議論などは自己関連性が高く、社会的影響の閾値が急峻（厳格）になる。
2.  **反応システム (Response System):** 反応のレベルによって閾値の位置が変わる。
    *   **低次システム:** 無意識の反射やプロセス。閾値は低く、容易に社会的影響が生じる。
    *   **高次システム:** 意識的・目的的な行動（言語コミュニケーション等）。閾値は高くなる。

### 3.2 閾値のダイナミクス
モデルによれば、エージェンシーが低い（＝エージェントである）場合、社会的影響を与えるには極めて高い行動のリアリズムが必要となる。逆に、エージェンシーが高い（＝アバターである）場合、行動のリアリズムが低くても社会的影響が生じやすい。

## 4. 重要な引用と背景

> 「[社会心理学とは] 他者の実際の、想像上の、あるいは暗示された存在によって、個人の思考、感情、行動がどのように影響されるかを理解し、説明しようとする試みである。」 —— Gordon Allport, 1954 [1]

**背景:** この広範な定義は、IVE内での社会的影響を想定するための強固な基礎となる。他者が物理的に存在しなくても、デジタルな「他者」を通じて社会的影響が起こり得ることを示唆している。

> 「優れた理論ほど実用的なものはない。」 —— Kurt Lewin, 1951 [2]

**背景:** 社会心理学者が持つ明示的な理論モデルは、IVEの設計や実用的なアプリケーション開発において、人間の直感よりも優れた成果をもたらすとブラスコビッチは主張している。

> 「我々は存在感（Presence）を、個人が自分自身をある環境内に存在していると知覚する心理状態と定義する。」

**背景:** 存在感は「仮想」か「現実」かの二元論ではなく、個人の知覚に依存する心理的構成概念であることを強調している。

## 5. 主要な研究成果の分析

RECVEB（Research Center for Virtual Environments and Behavior）における実験データは、モデルの妥当性を裏付けている。

### 5.1 社会的促進と抑制 (Social Facilitation/Inhibition)
*   **内容:** 他者の存在下で、習熟したタスクのパフォーマンスが向上（促進）し、未知のタスクが低下（抑制）する現象。
*   **結果:** IVE内において、観察者が「アバター」であると信じている場合にのみ、未知のタスクにおける社会的抑制が発生した。「エージェント」であると信じている場合には、この影響は見られなかった。

### 5.2 同調 (Conformity)
*   **内容:** ブラックジャックの賭け金において、周囲の仮想プレイヤーの規範に合わせるかどうかを調査。
*   **結果:** 参加者はエージェント、アバター双方の条件で周囲に同調した。しかし、アバター条件の方が全体的な賭け金が高くなった。これは、同調が低次の（無意識的な）プロセスである一方で、他者と自分を比較する「社会的比較」が高次のプロセスとしてアバター条件でより強く働いたためと考えられる。

### 5.3 プロクセミクス (Proxemics)
*   **内容:** 仮想エージェントへの接近距離を測定。
*   **結果:** エージェントの行動のリアリズム（まばたきや視線の追従など）が高い場合、参加者はより広い対人距離を維持した。この効果はエージェンシー（相手が人間かコンピュータか）に依存せず、低次の反応システムとして作用していた。

## 6. 実践的インサイトと今後の展望

IVE技術の発展は、社会心理学研究に以下の革新をもたらす。

1.  **不可能だった操作の実現:** IVE内では、参加者の性別、人種、年齢、身体的サイズといった「組織的・人口統計学的特性」を実験的に変更し、社会的アイデンティティの影響を調査できる。
2.  **自己との相互作用:** 参加者が「自分自身」と相互作用する状況を作り出し、これまでの理論ではテスト不可能だった自己の概念を検証できる。
3.  **高次と低次のプロセスの分離:** 特定の反応が意識的なものか、あるいは自動的なものかを、エージェンシーとリアリズムの操作によって区別できる。
4.  **研究の経済性とポータビリティ:** デジタルIVEは構築コストが低下しており（1ユーザーあたり25,000〜40,000ドル）、従来の「金槌と釘」で作られた物理的な実験設備よりも柔軟で持ち運びが可能である。

### 結論
IVEは単なる物理世界のシミュレーション装置ではなく、人間の社会的性質を解明するための高度な実験ツールである。優れた理論に導かれたIVEアプリケーションの開発は、今後「アバターたちの社会生活」をさらに向上させていくことになるだろう。
